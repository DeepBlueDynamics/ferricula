The Rust Crate Blueprint

Seventeen modules across three agent jurisdictions. Built on Roaring Bitmaps, tiny_http, and zero external HTTP clients.

memory.rs

Fidelity Envelope

Wraps raw data in thermodynamic metadata. Manages lifecycle transitions from Active to Archived.

struct MemoryRecord { fidelity: f32, ... }
graph.rs

Adjacency Map

Bidirectional edges with canonical keys. Bitmaps for neighbor lookup and 2-hop path searching.

type EdgeMap = HashMap<u32, Bitmap>
dream.rs

Consolidation Loop

Six-phase dream: decay, forgive, consolidate, neglect, review, prune. Entropy-driven scheduling.

fn dream_cycle(&mut self) -> DreamReport
casting.rs

Hexagram Engine

King Wen 8x8 table, yarrow stalk probabilities, trigram-to-emotion mapping, zodiac from epoch.

fn cast_hexagram(entropy: &[u8]) -> HexagramCast
identity.rs

Agent Identity

Load or create singleton identity from entropy. Persists as identity.json. Creates keystone anchor.

fn load_or_create(dir, entropy) -> IdentityState
http.rs

HTTP Service

tiny_http thread with 16 endpoints. Channel-based dispatch to main thread via HttpCommand enum.

fn spawn_http(port, tx, running) -> JoinHandle
clock.rs

Entropy Clock

Polls gnosis-radio for time + entropy. Reservoir accumulation. Dream triggers at threshold.

fn spawn_clock(config) -> (Receiver, Telemetry)
inversion.rs

Semantic Fidelity

Vec2text quality check via chonk /invert. Jaccard word overlap measures if meaning survived decay.

fn check_inversion(url, id, text, vec) -> Check

HTTP API Reference

16 endpoints served on --serve [port] (default :8765). All responses are application/json with CORS headers.

Memory Operations
